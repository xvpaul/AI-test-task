# Развёртывание OpenClaw — чек-лист

**Стек:** OpenClaw в Docker на зарубежном VPS · Google AI Studio (Gemini Flash) · Telegram

---

## Перед началом — собрать три вещи

| Что | Где взять |
|---|---|
| API-ключ Gemini | [aistudio.google.com](https://aistudio.google.com) → Get API key. Карта не нужна. |
| Токен Telegram-бота | `@BotFather` → `/newbot` |
| Свой numeric ID | `@userinfobot` → пишет число вида `123456789` |

Бесплатный тир Gemini: 15 запросов/минуту, 1500 запросов/сутки, контекст до 1M токенов.
Промпты бесплатного тира могут использоваться Google для улучшения моделей — для тестового
задания это неважно, но знать стоит.

---

## Шаг 1. Подготовить сервер

VPS **за пределами РФ** (Германия, Нидерланды, Финляндия). Минимум 2 ГБ RAM —
6 ГБ из документации нужны только для локальной сборки образа, а мы берём готовый.

```bash
# Docker + Compose v2
curl -fsSL https://get.docker.com | sh
docker compose version   # убедиться, что v2+
```

## Шаг 2. Развернуть OpenClaw

```bash
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# Готовый образ вместо локальной сборки — быстрее и не требует 6 ГБ RAM
export OPENCLAW_IMAGE="ghcr.io/openclaw/openclaw:latest"
./scripts/docker/setup.sh
```

Скрипт сам проведёт онбординг: спросит ключи, сгенерирует gateway-токен, создаст директории.
Конфиг монтируется в `/home/node/.openclaw` — переживает пересоздание контейнера.

## Шаг 3. Положить конфиг

Скопировать конфиг в смонтированный том на хосте, **обязательно под именем
`openclaw.json`** — шлюз читает `~/.openclaw/openclaw.json` и файлы с другими
именами молча игнорирует, стартуя на дефолтах. Расширение `.json`, содержимое
при этом в формате JSON5: комментарии и висячие запятые допустимы.

Подставить три значения вместо заглушек: ключ Gemini, токен бота, свой numeric ID.

> ⚠️ Если онбординг из шага 2 уже записал ключи куда-то ещё — не дублируйте их в конфиге,
> проверьте, что получилось после мастера, и правьте по месту. Возможно, ключ ожидается
> в переменной окружения, а не в файле; в этом случае секцию `apiKey` из конфига уберите.

Туда же положить `SOUL.md` — персональную инструкцию ассистента.

```bash
# Применить изменения конфига (restart не подхватывает env!)
docker compose up -d openclaw-gateway
```

## Шаг 4. Проверить, что шлюз жив

```bash
docker compose logs -f openclaw-gateway
openclaw gateway status
```

Дашборд: `http://127.0.0.1:18789/`, вход по gateway-токену из шага 2.

> ⚠️ Шлюз слушает **`0.0.0.0:18789`**, а не localhost — проверено через `ss -lntp`
> на сервере, в логах это же видно как предупреждение о привязке к non-loopback.
> Снаружи порт закрыт только файрволом: `curl` с другой машины отваливается
> по таймауту, а не по `connection refused`. Значит защита держится на ufw
> или файрволе провайдера, и при его отключении панель станет публичной —
> с одним лишь gateway-токеном на входе. Проверять так:
>
> ```bash
> ss -lntp | grep 18789                                  # на сервере
> curl -m 5 -o /dev/null -w '%{http_code}\n' http://<IP>:18789/   # снаружи
> ```

Для доступа с ноутбука пробросить SSH-туннелем:

```bash
ssh -L 18789:127.0.0.1:18789 user@ваш-сервер
```

Дальше открыть `http://127.0.0.1:18789/` уже у себя в браузере.

## Шаг 5. Привязать Telegram

```bash
openclaw pairing list telegram
openclaw pairing approve telegram <КОД>
```

Код живёт час — не тянуть.

## Шаг 6. Тест

Написать боту в личку. Если ответ пришёл — Этапы 1 и 2 закрыты: сервер вне РФ,
VPN не нужен ни на нём, ни на телефоне.

---

## Шаг 7. Перевыпустить API-ключ

Текущий ключ в `openclaw.config.json5` фигурировал в переписке с AI. Если планируете
прикладывать скриншоты диалогов к заданию — удалите его в
[aistudio.google.com](https://aistudio.google.com) и выпустите новый, иначе отдадите
рабочий ключ вместе со скриншотами.

Новый ключ подставить только на сервере, в чат не копировать.

## Шаг 8. Перед сдачей задания

HR будет проверять бота в реальном времени, но `dmPolicy: "allowlist"` пустит только вас —
все остальные получат тишину, неотличимую от сломанного бота.

Выбран **`open`**: проверяющий пишет когда ему удобно, дежурить у телефона не нужно.
Плата за это — отвечать бот будет любому, кто узнает username, а квота бесплатного
тира Gemini (1500 запросов в сутки) общая на всех.

```bash
gh variable set TELEGRAM_DM_POLICY --body open   # включить на время проверки
gh variable set TELEGRAM_DM_POLICY --body allowlist   # вернуть после
gh workflow run deploy.yml                       # применить: push не произойдёт
```

> ⚠️ **`open` без изоляции сессий — утечка переписки.** По умолчанию
> `session.dmScope` равен `main`, и все личные диалоги сходятся в один общий
> контекст: посторонний, написавший боту, оказывается в переписке владельца.
> В конфиге выставлено `dmScope: "per-channel-peer"` — сессии разводятся по паре
> «канал + отправитель». Проверить после деплоя: написать боту со второго
> аккаунта и убедиться, что он не знает содержания вашего диалога.

Альтернатива, если захочется контроля обратно: `pairing` — проверяющий пишет,
вы подтверждаете через `openclaw pairing approve telegram <КОД>`. Код живёт час,
то есть реагировать нужно быстро.

И держите Gateway запущенным — задание прямо требует, чтобы бота можно было проверить вживую.

## Если что-то не работает

| Симптом | Куда смотреть |
|---|---|
| Бот молчит | `docker compose logs -f openclaw-gateway` — ошибки провайдера видны там |
| 401/403 от Gemini | Ключ не подставился или `baseUrl` без завершающего `/` |
| 429 от Gemini | Упёрлись в 15 RPM или 1500 RPD — должен сработать fallback на Flash-Lite |
| Модель не найдена | ID модели устарел: проверить актуальные на [ai.google.dev/gemini-api/docs/models](https://ai.google.dev/gemini-api/docs/models) |
| Правки конфига не применяются | `restart` не перечитывает env — нужен `docker compose up -d` |

## Для скринкаста (Этап 3, 2–5 мин)

1. Терминал с `openclaw gateway status` + дашборд на `:18789`
2. Сообщение боту **с компьютера** → ответ
3. Сообщение боту **с телефона** → ответ
4. Крупным планом показать, что **VPN выключен** — до отправки сообщения
5. Голосом: что делали, где споткнулись

Что честно рассказать про трудности — материал уже есть:
подписка Claude Pro не даёт доступа к API (это отдельный продукт с отдельной оплатой),
у OpenAI постоянного бесплатного тира нет и минимум $5 + карта, поэтому выбрали
Google AI Studio — единственный бесплатный тир без карты с адекватными лимитами.
Подключается не готовым провайдером, а через OpenAI-совместимый эндпоинт и кастомный `baseUrl`.
